3. Quantitative Formulations & Core Invariants

Order Flow Imbalance (OFI) Cont et al. (2014)

Quantifies net buyer vs. seller liquidity innovation across 20 depth levels:

OFI = Σ [w_i * (ΔB_i - ΔA_i)] / Denom
where w_i = 1 / sqrt(i + 1)

Bounded strictly in [-1.0, 1.0]. Captures immediate liquidity pressure.

Fractional Kelly Sizing Conservative Sizing

Dynamically sizes positions according to model statistical win probability:

f* = [p * b - (1 - p)] / b
f_safe = 0.25 * f* (Quarter-Kelly)

b = payoff ratio. Size clamped between $5 minNotional and $100 cap.

Two-Sample KS Drift Test Concept Drift

Monitors empirical cumulative distribution divergence between train and live:

D = sup | F_train(x) - F_live(x) |
Trigger if p-value < 0.01 on >2 core features

Evaluated every 5 minutes against the latest 50 closed candles.

Page-Hinkley Change Detector Error Accumulator

Detects abrupt structural shifts in cumulative prediction error:

U_n = Σ (e_i - e_avg - δ)
Trigger if (U_n - min(U_k)) > λ (λ = 5.0)

Instantly retires active canary models to flat cash upon regime breaks.
